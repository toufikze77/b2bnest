B2BNEST logo files (transparent backgrounds)

mark      = square B2N symbol.   wordmark = B2BNEST lettering.
color     = brand blue #0069FF + navy #001A4C, for white/light backgrounds
reversed  = light blue #3D8BFF + white, for navy/dark backgrounds
white     = all white, for photos or blue backgrounds
navy      = all navy, for one-colour printing

svg/  vector files: sharp at any size (use these first)
png/  transparent PNGs; the number is the width in pixels

Rebuilt as vectors from the artwork supplied by the owner, in flat brand colours (the blue gradient in the original artwork is flattened to #0069FF). The tagline lines are not included.
